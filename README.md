# TeddyPups U.A.E. clone

Next.js 15 (App Router) clone of puppy.instabizweb.com: home, puppies (filters), puppy detail, happy families, how it works, FAQ (with FAQPage JSON-LD), contact letter form (`/api/contact`), gone-home tickets.

```bash
npm install
npm run dev     # http://localhost:3000
npm run build && npm start
```

Deploy: import the repo on Vercel (zero config).
